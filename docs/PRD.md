# HotMonitor - AI 热点监控系统

## 产品需求文档（PRD）

**版本**：v1.0  
**日期**：2026-05-10  
**作者**：AI 编程博主工具项目

---

## 一、背景与目标

作为 AI 编程博主，需要第一时间获取 AI 大模型更新、AI 编程工具发布等领域热点，无法依赖人工手动搜索。本产品旨在：

- **自动监控**指定关键词，发现真实热点后立即推送通知
- **自动发现**指定领域内的最新热点，聚合展示
- 利用 AI 识别真实内容，过滤噪音和营销文章

---

## 二、用户角色

| 角色 | 描述 |
|------|------|
| 博主（管理员） | 唯一用户，配置监控关键词、领域、接收通知 |

## 三、功能需求

### 3.1 关键词监控（Keyword Monitor）

**功能描述**：用户手动添加要监控的关键词，系统定期从多数据源搜索，AI 验证后推送通知。

**用户故事**：
- 作为博主，我想添加"Claude 5"关键词，当 X/HN 上出现真实的 Claude 5 相关内容时，立即收到通知
- 作为博主，我想暂停/删除不再需要的监控项

**功能点**：
1. 添加关键词监控（关键词 + 描述 + 监控频率）
2. 查看所有监控项列表（含状态：活跃/暂停）
3. 暂停/恢复/删除监控项
4. 查看某关键词的历史发现记录
5. 发现真实热点时 → 推送浏览器通知 + 邮件通知

**AI 验证规则**：
- 判断内容是否真实发布（非转载/营销/猜测）
- 判断内容是否与关键词高度相关
- 过滤重复内容（相同事件的多篇报道只通知一次）
- 输出：`{ isHot: boolean, confidence: number, reason: string, summary: string }`

---

### 3.2 热点自动发现（Hot Spot Discovery）

**功能描述**：用户配置感兴趣的领域，系统每小时自动聚合多源热点，AI 排序后展示。

**用户故事**：
- 作为博主，我想看到"AI 编程"领域今天的 Top 10 热点
- 作为博主，我想标记某条热点为"已看"或"收藏"

**功能点**：
1. 配置发现领域（如"AI 编程"、"大模型"、"AI Agent"）
2. 查看热点榜单（按热度分/时间排序）
3. 查看每条热点的来源、摘要、原文链接
4. 标记已读 / 收藏
5. 手动触发刷新

**热度评分算法**（AI 辅助）：
- 多源出现次数（越多来源提及 → 分越高）
- 互动数据（转发/点赞/评论数）
- 时效性（越新 → 分越高）
- AI 判断话题重要程度（0-10 分）

---

### 3.3 通知中心（Notification Center）

**功能描述**：集中展示所有推送历史，管理已读/未读状态。

**功能点**：
1. 站内通知列表（时间倒序）
2. 浏览器 Push 通知（需用户授权）
3. 邮件通知（SMTP 配置）
4. 未读数量角标
5. 全部标记已读

## 四、非功能需求

| 项目 | 要求 |
|------|------|
| 响应式 | 支持桌面端和移动端 |
| 本地运行 | 无需云端部署，本地 Node.js 运行 |
| 轻量级 | SQLite 数据库，无需额外服务 |
| 安全性 | API Key 存储在 .env，不暴露到前端 |
| 可扩展 | 后续可封装为 Agent Skills |
