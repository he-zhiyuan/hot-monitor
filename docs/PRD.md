# HotMonitor - AI 热点监控系统

## 产品需求文档（PRD）

**版本**：v1.3  
**更新**：2026-05-16  
**作者**：AI 编程博主工具项目

---

## 一、背景与目标

作为 AI 编程博主，需要第一时间获取 AI 大模型更新、AI 编程工具发布等领域热点，无法依赖人工手动搜索。本产品旨在：

- **自动监控**指定关键词，发现真实热点后立即推送通知
- **自动发现**指定领域内的最新热点，聚合展示
- 利用 AI 识别真实内容，过滤噪音和营销文章

## 三、功能需求

### 3.1 关键词监控（Keyword Monitor）

**功能描述**：用户手动添加要监控的关键词，系统定期从多数据源搜索，AI 验证后推送通知。

**用户故事**：
- 作为博主，我想添加"Claude 5"关键词，当 X/HN/Reddit 上出现真实的 Claude 5 相关内容时，立即收到通知
- 作为博主，我想暂停/删除不再需要的监控项

**功能点**：
1. 添加关键词监控（关键词 + 描述 + 监控频率 + 可选最低相关度）
2. 创建/改词时自动生成 **Query Expansion**（命中短语 + 模型提示）
3. 查看所有监控项列表（含状态：活跃/暂停）
4. 暂停/恢复/删除监控项
5. 查看某关键词的历史发现记录（摘要与判定分栏展示）
6. 相关且达阈值 → Socket.IO + 邮件；弱相关 → **仅入库不推送**

**AI 验证规则**：
- **本地预筛**：扩展短语命中 + 多 token 多数匹配，减少泛词误进 AI
- 判断内容是否真实发布（非转载/营销/猜测）
- **实体匹配**：`primary` / `related_product` / `tangential` / `unrelated`（同品牌不同产品降权）
- 相关度 0–1，须与实体层级一致；附原文 **evidence** 摘录
- 推送条件：`isReal && relevance >= minRelevance`（默认 0.65，可按监控配置）
- 过滤重复 URL 通知（24h 内同一链接只推一次）
- 输出：`{ isReal, relevance, entityMatch, evidence, summary, reason }`；Finding 存 `aiSummary` + `aiReason`

### 3.2 热点自动发现（Hot Spot Discovery）

**功能描述**：用户配置感兴趣的领域，系统每小时自动聚合多源热点，AI 排序后展示。

**用户故事**：
- 作为博主，我想看到"AI 编程"领域今天的 Top 10 热点
- 作为博主，我想标记某条热点为"已看"或"收藏"

**功能点**：
1. 配置发现领域（如"AI 编程"、"大模型"、"AI Agent"）
2. 查看热点榜单（按热度分/时间排序）
3. 查看每条热点的来源、摘要、原文链接
4. 标记已读 / 收藏
5. 手动触发刷新

**热度评分算法**（AI 辅助）：
- 多源出现次数（越多来源提及 → 分越高）
- 互动数据（转发/点赞/评论数）
- 时效性（越新 → 分越高）
- AI 判断话题重要程度（0-10 分）

---

### 3.3 通知中心（Notification Center）

**功能描述**：集中展示所有推送历史，管理已读/未读状态。

**功能点**：
1. 站内通知列表（时间倒序）
2. Socket.IO 实时推送（无需刷新页面）
3. 邮件通知（SMTP 配置）
4. 未读数量角标
5. 全部标记已读

## 四、数据源（v1.1 扩展）

| 来源 | 类型 | 质量控制 | 说明 |
|------|------|---------|------|
| Twitter/X | 付费 API | API 层：min_faves:10 + -is:reply；本地层：综合互动分过滤 | 可选，质量最高但有成本 |
| Hacker News | 免费 API | points>10, num_comments>5（热点模式） | 英文技术社区 |
| GitHub Trending | 爬虫 | 每日 Trending 天然过滤 | 仅代码仓库 |
| Reddit | 免费 JSON API | score >= 5/10，限定 AI 相关子版块 | 社区讨论，中英文混合 |
| Dev.to | 免费官方 API | 按 AI 标签过滤，top=1 热度排序 | 技术文章 |
| Google News RSS | 免费 RSS | 中英文双源合并去重 | 新闻报道 |
| Bing 搜索 | 爬虫 | - | 兜底搜索 |

## 五、非功能需求

| 项目 | 要求 |
|------|------|
| 响应式 | 支持桌面端和移动端 |
| 本地运行 | 无需云端部署，本地 Node.js 运行 |
| 轻量级 | SQLite 数据库，无需额外服务 |
| 安全性 | API Key 存储在 .env，不暴露到前端 |
| 可扩展 | 数据源适配器解耦，新增来源只需添加一个文件 |
| 容错性 | 任意数据源失败不影响其他源，错误仅日志记录 |

## 六、产品边界（MVP 范围）

**已完成**：
- 关键词监控 + AI 验证（含 Query expansion、分层相关性、可配置推送阈值）
- 热点自动发现（10 个数据源）
- 实时推送（Socket.IO）+ 邮件通知
- Web 仪表板 UI（深色玻璃拟态）
- Twitter 质量过滤优化
- **Cursor Agent Skill**（`.cursor/skills/hot-monitor/`）：Python 多源 CLI + Agent 侧验证；支持博主摘要（`creators.yaml`）；不替代 Web 的持久化与通知

**不包含（后续迭代）**：
- 多用户支持
- 微信通知
- 移动 App
